مستشفى طيبة - مشروع تعليمي

طريقة التشغيل:
1) فك ضغط الملف بالكامل.
2) افتح مجلد Taiba_Hospital في Visual Studio Code.
3) افتح login.html باستخدام إضافة Live Server (ضروري لتحميل ملفات components).
   ويمكنك أيضًا تشغيل index.html؛ سيحوّلك تلقائيًا إلى صفحة تسجيل الدخول إذا لم تسجل الدخول بعد.
4) سجل بيانات تجريبية للدخول. لا تستخدم كلمة مرور حقيقية.

المحتويات:
- صفحة تسجيل الدخول ثم الصفحة الرئيسية.
- 21 صفحة تخصص مستقلة بصور طبية فوتوغرافية مناسبة لكل تخصص.
- صور محلية داخل images/medical حتى تظهر دون الاعتماد على مواقع الصور.
- ملفات CSS وJavaScript منفصلة، وملفات topbar وnavbar منفصلة داخل components.
- تأثيرات حركة للصور والخلفية منشأة/مفعّلة بواسطة JavaScript مع CSS للحركة.
- بحث عن الأقسام، معلومات تثقيفية، اختيار طبيب ونموذج حجز تجريبي.

ملاحظة: تسجيل الدخول والحجز واجهة تجريبية تعمل داخل المتصفح فقط، ولا يوجد خادم أو قاعدة بيانات أو إرسال حقيقي للحجوزات. المعلومات الطبية للتوعية وليست تشخيصًا أو علاجًا.

صور الأقسام: لكل صفحة قسم صورة داخلية مستقلة ومختلفة عن صورة بطاقة القسم في الصفحة الرئيسية، وجميعها بنفس أسلوب العرض والتنسيق. الصور موجودة داخل images/medical/inside.
